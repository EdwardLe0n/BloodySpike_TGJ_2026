## Conceptually...

### In a sentence...

It's an arcade style game in which you drink blood, spill others blood, and impale your spike into the ground to cause a chain effect of other spikes to rupture from pools of blood.

### Core Loops

1. Move around and attack enemies
2. Collect/leave pools of blood
3. Impale the ground to create spikes

### Pillars

#### Core Pillars

1. Fight
2. Spill
3. Chain

#### Secondary Pillars

1. Melee/thrown
2. More attacks in a time frame can increase further blood spilt?
3. Leaving pools of blood

### Controls

#### Keyboard

- ***w == foward***
- ***a/d == turn***
- s == backward
- ***j (press) == attack***
- j (hold) == charge attack
- k (press) == throw
- k (hold) == stab
- ***l (hold) == suck***

#### Gamepad

- Left stick == movement
- right (press) == attack
- right (hold) == charge attack
- down (press) == throw
- down (hold) == stab

### Other Mechanics

- Moving cause blood to leave sword
- Blood consistently leaves the players health except for one blood ball
